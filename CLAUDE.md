# jev-model-routing

## Response style — Minto Pyramid (always)

Write every chat reply, summary, and rewrite using the Minto Pyramid
Principle:

1. **Main conclusion first** — the answer or recommendation in one or two
   sentences, before any background.
2. **2–4 key supporting reasons** beneath it, each a short standalone claim.
3. **Supporting evidence under each reason** — facts, data, file
   references, or examples that back that specific reason.
4. **Cut everything else** — no preamble, restated questions, or details
   that don't support a reason.
5. **Flag missing critical information** — end with a short "Missing
   information" note naming anything needed to make the conclusion solid
   (omit it when nothing is missing).

When the user pastes text to rewrite, apply the same structure to their
text. Code, commit messages, and files whose format is set by a template or
tool keep that format — this rule governs prose replies and rewritten text.
